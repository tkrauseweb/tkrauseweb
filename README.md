### [ITMScore](https://itmscore.de/)

Ein webbasiertes IT-Management-System für Inventar, Wartungen und Aufgaben. Das Praxisprojekt verbindet Softwareentwicklung, Systemadministration, sicheren Betrieb und technische Dokumentation.

**Schwerpunkte**

- zentrale Verwaltung von Geräten, Wartungen und Aufgaben
- Entwicklung einer vollständigen Webanwendung mit geschütztem Anwendungsbereich
- selbst gehosteter Betrieb und praxisnahe Systemadministration
- nachvollziehbare Projekt- und Betriebsdokumentation

**Technik:** TypeScript · React · Node.js · PostgreSQL · Docker · Caddy

[🌐 Projektseite ansehen](https://itmscore.de/) · [🚀 Anwendung öffnen](https://app.itmscore.de/)

### [Montagemagerquark](https://montagemagerquark.onrender.com/)

Eine humorvolle, responsive One-Page-Website im industriellen Retro-Look – mit Quarkrezepten, Eiweißparolen und einem digitalen Schichtplaner.

**Highlights**

- interaktiver „Quarkomat 84“ mit persönlichen Schichtempfehlungen
- animierte Litfaßsäule, Rezepte und wechselnder „Quark des Tages“
- responsive und barrierearme Umsetzung ohne Framework
- SEO-Metadaten, strukturierte Daten und Google Search Console
- automatische Veröffentlichung über GitHub und Render

**Technik:** HTML5 · CSS3 · Vanilla JavaScript · Render · GitHub Pages

[🚀 Live ansehen](https://montagemagerquark.onrender.com/) · [📦 Repository öffnen](https://github.com/tkrauseweb/montagemagerquark)
